# Ayoub Ahmed - Portfolio Website

A modern, fully responsive portfolio website built with React, TailwindCSS, Framer Motion, and React Three Fiber.

## Features

- 🎨 Modern UI with light/dark theme toggle
- 📱 Fully responsive design (mobile-first)
- ✨ Smooth animations with Framer Motion
- 🎭 3D elements using React Three Fiber
- 🚀 Optimized performance with lazy loading
- ♿ Fully accessible with ARIA attributes

## Tech Stack

- **React** - UI library
- **Vite** - Build tool
- **TailwindCSS** - Styling
- **Framer Motion** - Animations
- **React Three Fiber** - 3D graphics
- **Lucide React** - Icons

## Getting Started

### Prerequisites

- Node.js 18+ and npm/yarn/pnpm

### Installation

1. Install dependencies:
```bash
npm install
```

2. Start development server:
```bash
npm run dev
```

3. Build for production:
```bash
npm run build
```

4. Preview production build:
```bash
npm run preview
```

## Project Structure

```
src/
├── components/     # React components
├── data/          # Static data files
├── utils/         # Utility functions
├── App.jsx        # Main app component
├── main.jsx       # Entry point
└── index.css      # Global styles
```

## Customization

- Update personal information in `/src/data/about.js`
- Modify navigation links in `/src/data/navLinks.js`
- Add/remove skills in `/src/data/skills.js`
- Update projects in `/src/data/projects.js`
- Change social links in `/src/data/socials.js`
